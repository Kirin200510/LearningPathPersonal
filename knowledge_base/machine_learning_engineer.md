# Kỹ sư Machine Learning


> Tài liệu này dùng để định hướng học tập và xây dựng lộ trình cá nhân hóa. 
> Nó không phải cam kết về tuyển dụng, mức lương hoặc thời gian chắc chắn để có việc.


## Nghề này làm gì?

Machine Learning Engineer biến mô hình machine learning thành thành phần phần mềm có thể huấn luyện, triển khai, giám sát và cập nhật. Vai trò này nằm giữa software engineering, data engineering và data science.

## Công việc thường gặp

- Chuẩn hóa pipeline dữ liệu và huấn luyện.
- Đóng gói model thành API hoặc batch job.
- Quản lý phiên bản dữ liệu, model và cấu hình.
- Theo dõi latency, lỗi, chất lượng dự đoán và drift.
- Tối ưu tài nguyên khi inference.
- Phối hợp với data scientist và đội sản phẩm.

## Phù hợp với ai?

Phù hợp với người thích cả machine learning và xây dựng hệ thống. Nếu chỉ thích phân tích mô hình mà không muốn triển khai, Data Scientist có thể gần hơn. Nếu thích backend và hạ tầng, ML Engineer là hướng phù hợp.

## Nền tảng cần có

1. Python tốt.
2. Cấu trúc dữ liệu, OOP và testing.
3. SQL và xử lý dữ liệu.
4. Machine learning căn bản.
5. API, Docker và Linux.
6. Git, CI/CD và monitoring ở mức cơ bản.

## Lộ trình học đề xuất

### Giai đoạn 1: Software engineering

Viết package Python, type hint, test, logging, configuration và quản lý dependency.

### Giai đoạn 2: Machine learning

Dùng scikit-learn để xây preprocessing pipeline, baseline, training và đánh giá. Hiểu overfitting, leakage và reproducibility.

### Giai đoạn 3: Deep learning

Dùng PyTorch khi bài toán phù hợp. Hiểu dataset, dataloader, checkpoint, inference và thiết bị tính toán.

### Giai đoạn 4: Model serving

Đóng gói model thành API, xác thực input, batch prediction, timeout và xử lý lỗi.

### Giai đoạn 5: Container và pipeline

Dùng Docker, tự động hóa test, build và triển khai. Lưu artifact và metadata của model.

### Giai đoạn 6: Monitoring

Theo dõi dữ liệu đầu vào, latency, lỗi, chất lượng dự đoán và drift. Chuẩn bị quy trình rollback hoặc huấn luyện lại.

## Dự án portfolio nên làm

1. API phân loại văn bản có test và Docker.
2. Hệ thống gợi ý khóa học gồm training pipeline và inference service.
3. Pipeline huấn luyện định kỳ có lưu metric, model version và báo cáo.

## Tiêu chí tự đánh giá

Bạn có thể tái tạo kết quả huấn luyện, triển khai model, kiểm tra input, theo dõi lỗi và giải thích khi nào cần cập nhật model.

## Sai lầm thường gặp

- Chỉ có notebook, không có code sản phẩm.
- Không lưu phiên bản model và dữ liệu.
- Không kiểm tra input hoặc trường hợp ngoài phân phối.
- Dùng LLM cho mọi bài toán mà không có baseline.
- Chỉ quan tâm accuracy mà bỏ qua latency, chi phí và vận hành.

## Nghề liên quan

Data Scientist, Data Engineer, Backend Developer, MLOps Engineer và Applied AI Engineer.
