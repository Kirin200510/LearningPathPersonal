# Nhà khoa học dữ liệu


> Tài liệu này dùng để định hướng học tập và xây dựng lộ trình cá nhân hóa. 
> Nó không phải cam kết về tuyển dụng, mức lương hoặc thời gian chắc chắn để có việc.


## Nghề này làm gì?

Data Scientist sử dụng dữ liệu, thống kê và machine learning để khám phá quy luật, dự báo hoặc hỗ trợ quyết định. Công việc thường bao gồm xác định bài toán, chuẩn bị dữ liệu, xây baseline, đánh giá mô hình và truyền đạt giới hạn của kết quả.

## Công việc thường gặp

- Khám phá và làm sạch dữ liệu.
- Xây đặc trưng và mô hình thống kê hoặc machine learning.
- Thiết kế cách đánh giá và so sánh mô hình.
- Trực quan hóa, giải thích kết quả và bất định.
- Thử nghiệm giả thuyết.
- Phối hợp đưa mô hình vào sản phẩm.

## Phù hợp với ai?

Phù hợp với người thích toán ứng dụng, lập trình và phân tích. Người học cần thoải mái với việc kết quả không hoàn hảo và phải giải thích giới hạn dữ liệu.

## Nền tảng cần có

1. Python và SQL.
2. Xác suất, thống kê và đại số tuyến tính căn bản.
3. Làm sạch và khám phá dữ liệu.
4. Trực quan hóa.
5. Machine learning căn bản.
6. Thiết kế đánh giá và tránh data leakage.

## Lộ trình học đề xuất

### Giai đoạn 1: Python cho dữ liệu

Học NumPy, pandas, notebook, biểu đồ và cách viết code có thể tái sử dụng.

### Giai đoạn 2: Thống kê

Học phân phối, sampling, confidence interval, hypothesis testing, correlation và regression.

### Giai đoạn 3: Machine learning căn bản

Học supervised, unsupervised, train/validation/test, preprocessing, feature engineering và pipeline với scikit-learn.

### Giai đoạn 4: Đánh giá

Chọn metric theo bài toán; hiểu class imbalance, cross-validation, overfitting và data leakage.

### Giai đoạn 5: Deep learning khi cần

Học tensor, dataset, model, loss, optimizer và training loop với PyTorch. Không dùng deep learning khi baseline đơn giản đã đủ.

### Giai đoạn 6: Dự án đầu cuối

Từ câu hỏi, dữ liệu, notebook khám phá, mô hình, đánh giá đến API hoặc báo cáo. Ghi rõ giới hạn và rủi ro.

## Dự án portfolio nên làm

1. Dự đoán nguy cơ bỏ học với chú ý đến mất cân bằng lớp.
2. Hệ thống gợi ý khóa học có baseline và đánh giá offline.
3. Phân tích văn bản phản hồi sinh viên với báo cáo lỗi và giới hạn.

## Tiêu chí tự đánh giá

Bạn có thể thiết lập baseline, chia dữ liệu đúng, chọn metric phù hợp, giải thích mô hình và tránh khẳng định quá mức.

## Sai lầm thường gặp

- Bắt đầu bằng mô hình phức tạp.
- Tối ưu metric nhưng bỏ qua ý nghĩa thực tế.
- Để dữ liệu tương lai rò rỉ vào tập huấn luyện.
- Chỉ trình bày notebook mà không giải thích quyết định.
- Coi correlation là causal effect.

## Nghề liên quan

Data Analyst, Machine Learning Engineer, Applied Scientist và Analytics Engineer.
