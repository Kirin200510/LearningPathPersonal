# Lập trình viên Frontend


> Tài liệu này dùng để định hướng học tập và xây dựng lộ trình cá nhân hóa. 
> Nó không phải cam kết về tuyển dụng, mức lương hoặc thời gian chắc chắn để có việc.


## Nghề này làm gì?

Frontend Developer xây dựng phần giao diện mà người dùng nhìn thấy và tương tác trên trình duyệt. Công việc bao gồm trình bày nội dung, xử lý tương tác, gọi API, quản lý trạng thái, hỗ trợ nhiều kích thước màn hình và bảo đảm trải nghiệm sử dụng ổn định.

## Công việc thường gặp

- Chuyển thiết kế thành HTML, CSS và JavaScript.
- Xây component và quản lý trạng thái giao diện.
- Tích hợp REST API và xử lý trạng thái loading, error, empty.
- Đảm bảo responsive, accessibility và tương thích trình duyệt.
- Tối ưu hiệu năng tải trang.
- Viết test giao diện và phối hợp với designer, backend.

## Phù hợp với ai?

Phù hợp với người thích kết quả trực quan, quan tâm trải nghiệm người dùng và sẵn sàng tinh chỉnh chi tiết. Frontend vẫn cần tư duy lập trình và debug; đây không chỉ là “làm đẹp giao diện”.

## Nền tảng cần có

1. HTML semantic.
2. CSS layout, responsive và box model.
3. JavaScript cơ bản đến bất đồng bộ.
4. HTTP, JSON và API.
5. Git và công cụ trình duyệt.
6. Accessibility và khả năng sử dụng.

## Lộ trình học đề xuất

### Giai đoạn 1: HTML và CSS

Học cấu trúc tài liệu, form, semantic, selector, cascade, flexbox, grid và responsive. Tự dựng nhiều giao diện nhỏ từ ảnh mẫu.

### Giai đoạn 2: JavaScript

Học biến, hàm, object, array, DOM, event, module, promise, async/await và xử lý lỗi. Viết ứng dụng không dùng framework trước.

### Giai đoạn 3: Làm việc với API

Dùng fetch, hiển thị dữ liệu, gửi form, quản lý token và xử lý lỗi. Hiểu CORS ở mức sử dụng.

### Giai đoạn 4: Framework

Chọn một framework như React hoặc Vue. Học component, props, state, lifecycle, routing và form. Không học nhiều framework cùng lúc.

### Giai đoạn 5: Chất lượng giao diện

Học accessibility, performance, test component, lint, format và tổ chức source code.

### Giai đoạn 6: Dự án thực tế

Kết hợp với backend, xác thực, phân quyền, pagination, search và deploy.

## Dự án portfolio nên làm

1. Trang dashboard responsive sử dụng API.
2. Ứng dụng quản lý học tập có đăng nhập và tiến độ.
3. Website thương mại nhỏ có tìm kiếm, giỏ hàng và trạng thái đơn.

## Tiêu chí tự đánh giá

Bạn có thể dựng giao diện từ thiết kế, gọi API, quản lý trạng thái, xử lý lỗi, tối ưu hiển thị trên mobile và giải thích cấu trúc component.

## Sai lầm thường gặp

- Học React trước khi nắm JavaScript.
- Dùng quá nhiều thư viện cho chức năng đơn giản.
- Chỉ làm giao diện tĩnh không có dữ liệu.
- Bỏ qua accessibility và trạng thái lỗi.
- Sao chép component nhưng không hiểu state và luồng dữ liệu.

## Nghề liên quan

Full-stack Developer, UI Engineer, Web Developer và Mobile Developer.
