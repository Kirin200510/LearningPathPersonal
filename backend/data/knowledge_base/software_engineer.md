# Kỹ sư phần mềm


> Tài liệu này dùng để định hướng học tập và xây dựng lộ trình cá nhân hóa. 
> Nó không phải cam kết về tuyển dụng, mức lương hoặc thời gian chắc chắn để có việc.


## Nghề này làm gì?

Kỹ sư phần mềm phân tích nhu cầu của người dùng, thiết kế giải pháp, viết mã nguồn, kiểm thử, triển khai và cải tiến phần mềm. Sản phẩm có thể là ứng dụng web, ứng dụng di động, hệ thống doanh nghiệp, dịch vụ nền hoặc công cụ nội bộ. Vai trò này không chỉ yêu cầu viết được code mà còn cần hiểu cách tổ chức chương trình, quản lý thay đổi, phối hợp nhóm và duy trì hệ thống trong thời gian dài.

## Công việc thường gặp

- Phân tích yêu cầu và chuyển yêu cầu thành chức năng phần mềm.
- Thiết kế module, API, cấu trúc dữ liệu và luồng xử lý.
- Viết code có khả năng đọc, kiểm thử và bảo trì.
- Sửa lỗi, tối ưu hiệu năng và cải tiến tính năng cũ.
- Review code và làm việc với Git theo quy trình nhóm.
- Viết tài liệu kỹ thuật và trao đổi với các bên liên quan.

## Phù hợp với ai?

Hướng này phù hợp với người thích giải quyết vấn đề bằng logic, kiên nhẫn khi tìm lỗi và sẵn sàng học nhiều công nghệ theo từng dự án. Bạn không cần giỏi toán nâng cao để bắt đầu, nhưng cần tư duy phân tích, khả năng chia một bài toán lớn thành các phần nhỏ và thói quen kiểm tra kết quả.

## Nền tảng cần có

1. Một ngôn ngữ lập trình chính như Python, Java, C# hoặc JavaScript.
2. Cấu trúc dữ liệu và giải thuật cơ bản.
3. Lập trình hướng đối tượng và nguyên tắc thiết kế cơ bản.
4. Git, dòng lệnh và môi trường phát triển.
5. Cơ sở dữ liệu quan hệ và SQL.
6. HTTP, API và kiến thức mạng căn bản.
7. Kiểm thử phần mềm và debug.

## Lộ trình học đề xuất

### Giai đoạn 1: Lập trình nền tảng

Học biến, kiểu dữ liệu, điều kiện, vòng lặp, hàm, module, xử lý lỗi và đọc ghi file. Mục tiêu là tự viết được chương trình nhỏ mà không phụ thuộc hoàn toàn vào hướng dẫn.

### Giai đoạn 2: Tư duy giải quyết vấn đề

Học mảng, danh sách, stack, queue, dictionary, set, tìm kiếm, sắp xếp và độ phức tạp ở mức căn bản. Không cần chạy theo bài thuật toán khó; ưu tiên hiểu cách chọn cấu trúc dữ liệu phù hợp.

### Giai đoạn 3: Xây dựng phần mềm có cấu trúc

Học OOP, tách lớp, tách module, dependency, logging, validation và configuration. Bắt đầu viết unit test cho các chức năng quan trọng.

### Giai đoạn 4: Dữ liệu và giao tiếp hệ thống

Học SQL, mô hình quan hệ, transaction, REST API, JSON, authentication và xử lý lỗi qua API.

### Giai đoạn 5: Làm dự án theo nhóm

Dùng Git branch, pull request, issue, code review và quy ước commit. Viết README, hướng dẫn chạy và mô tả kiến trúc.

### Giai đoạn 6: Chọn chuyên sâu

Sau nền tảng chung, chọn backend, frontend, mobile, data, DevOps, bảo mật hoặc kiểm thử. Không nên học dàn trải nhiều framework trước khi hoàn thành ít nhất một dự án đầu cuối.

## Dự án portfolio nên làm

1. Ứng dụng quản lý công việc có đăng nhập, phân quyền và database.
2. Hệ thống đặt lịch hoặc quản lý khóa học có API và giao diện.
3. Dự án nhóm có issue, pull request, test và tài liệu triển khai.

## Tiêu chí tự đánh giá

Bạn sẵn sàng ứng tuyển thực tập khi có thể giải thích kiến trúc dự án, tự sửa lỗi phổ biến, dùng Git theo nhánh, viết truy vấn SQL, xây một chức năng hoàn chỉnh và trình bày rõ phần mình đã làm.

## Sai lầm thường gặp

- Học nhiều framework nhưng thiếu nền tảng lập trình.
- Chỉ xem video mà không tự xây sản phẩm.
- Sao chép code nhưng không giải thích được luồng chạy.
- Bỏ qua kiểm thử, Git và tài liệu.
- Coi số lượng công nghệ quan trọng hơn chất lượng dự án.

## Nghề liên quan

Backend Developer, Frontend Developer, Mobile Developer, QA Engineer, DevOps Engineer, Data Engineer và Machine Learning Engineer.
